# Metacampo - Simulador de Carteira Inteligente

Metacampo is a premium agricultural portfolio management and simulation platform, designed to transform transient ERP data into actionable executive intelligence.

## 🚀 Vision
Built for the GTMGC SaaS ecosystem, Metacampo implements a memory-first architecture that enables consultants (CTV) and administrators to:
- **Visualize Portfolio Intelligence**: High-end dashboards with Valora design standards.
- **Calculate Market Potential**: ITAA-based engines for deep market analysis.
- **Client Scoring**: Multicriterial scoring for better decision making.
- **Operational Planning**: Visit capacity planning and financial budget management.

## 🛠 Tech Stack
- **Framework**: [Next.js 15+](https://nextjs.org) (App Router)
- **Styling**: Tailwind CSS 4.0
- **Database/Auth**: [Supabase](https://supabase.com)
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Testing**: Vitest

## 📋 Features
- **Pareto Segmentation**: Dynamic A/B/C client categorization.
- **Scoring Engine**: Customized business rules for client potential.
- **Visit Service**: Intelligent scheduling and capacity monitoring.
- **VPM Service**: Value Potential Market calculations.

## 🚦 Getting Started

### Prerequisites
- Node.js 20+
- Supabase Project

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Sagrado-Express/Metacampo.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Copy `.env.example` to `.env.local` and fill in your Supabase credentials.

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
