================================================================================

2. Execute script:
   node migrate.mjs

OPÇÃO 3️⃣ — PSQL CLI (MAIS DIRETO)
================================================================================

1. Instale PostgreSQL (psql):
   Windows: https://www.postgresql.org/download/windows/
   macOS: brew install postgresql
   Linux: sudo apt install postgresql-client

2. Execute:
   psql "postgresql://postgres:PASSWORD@db.jcnxinvycgluoeqixdul.supabase.co:5432/postgres" \
     < supabase/migrations/20260728093600_add_missing_tables.sql

   psql "postgresql://postgres:PASSWORD@db.jcnxinvycgluoeqixdul.supabase.co:5432/postgres" \
     < supabase/migrations/20260728093700_add_performance_indexes.sql

   (Substitua PASSWORD pela senha do postgres do Supabase)

Tempo: 3 minutos | Conhecimento: psql
